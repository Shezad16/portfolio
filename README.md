# Shezad.dev Portfolio

Simple personal portfolio built with:

- HTML5
- CSS3
- JavaScript

## Before publishing

Open `index.html` and replace these placeholders:

- `YOUR-LINKEDIN-URL`
- `YOUR-SWIFTPAY-GITHUB-URL`
- `YOUR-TODO-GITHUB-URL`
- `YOUR-THIRD-GITHUB-URL`
- `YOUR-THIRD-LIVE-DEMO-URL`

Also update the third project card with the real project name, description, technologies and screenshot if available.

## GitHub Pages

Create a public repository and upload the files. GitHub Pages can publish a static `index.html` site directly from a repository. See GitHub's Pages documentation for the current setup steps.

For a personal site, a repository named:

`Shezad16.github.io`

will give a user-site URL like:

`https://shezad16.github.io/`
